# 对话轮目录2-Nuwa部署

本夹是 **对话轮目录 2**，记本场对话。版式与 `files/对话轮目录1-Nuwa部署/` 相同：横表，列是标号、问题总结、答案概要、使用模型、对话时间。

浏览用 Menu：`对话轮目录2-本场对话之Menu.docx`。

## 更新方式

与目录1相同。用户说「更新目录」时，在 `对话轮目录2数据.json` 末尾追加本场新轮次，合并同一任务里的重复追问，更新 `updated_at`，再运行：

```bash
python3 更新目录.py
```

只改错字、补百分号、调表格主语、改文件名，不单列一条。

## 文件

- `对话轮目录2-本场对话之Menu.docx`：浏览用目录，标题含「对话轮目录2」。
- `对话轮目录2数据.json`：源数据。
- `更新目录.py`：DOCX 生成器。
