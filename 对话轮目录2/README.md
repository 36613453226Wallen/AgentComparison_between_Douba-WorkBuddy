# 对话轮目录2

与目录 1 相同的横表在 `NuwaSkill-Yao/files/对话轮目录2-Nuwa部署/对话轮目录2-本场对话之Menu.docx`。本夹里较早的那份 Word 用的是另一套书签排版，以横表那份为准。


| 文件 | 作用 |
| --- | --- |
| `对话轮目录2.docx` | 每轮对话的目录表 + 分页问答 |

版式沿用对话轮目录1：`comment-record-ASIFOUR` 仓库里的 `records/Cursor对话轮描述与跳转`。

## 目录表

首页一张表，每轮一行：轮次、大概对话总结、权重、跳转。

跳转列只给**重要且大段**的轮次。显示词只有 `§n`，避免把表撑宽。点它跳到后文该书签。一般轮次这一格是「—」。

每一轮问答最后都有「回表」，跳回目录表表头。

目录表后面有这场 Cursor 对话的整场入口：https://cursor.com/agents/bc-5c7f46fc-aeda-4983-9902-3dc0a5949044 。打开的是整场，不是某一轮。

表后面空行，再分页。问答从下一页开始。表变长占满首页时，问答仍从下一页起。

## 现在用的跳转

同一份 Word 里的书签：`§n` 到该轮问答，「回表」到表头。不打开 Cursor 网页。

要跳到 Cursor 里某一条原话，书签做不到。这场对话的整场入口是云端对话页，不是每一轮一条独立链接。
